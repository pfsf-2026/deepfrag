# Health app (Expo)

The client for the Health API in `../api`. One TypeScript codebase for web, iOS
and Android via Expo Router. See `../README.md` to run everything, and
`AGENTS.md` here for Expo-specific conventions (follow the versioned Expo docs).

```bash
npm install
npx expo start          # w = web, i = iOS simulator
npx tsc --noEmit && npx eslint src
```

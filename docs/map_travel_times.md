# Travel times between key rooms on the TB4 maps

*Seconds from entering one room to entering the other, measured from 64 recent NA fours (October 2026) through the demo parser's room trails. Each cell is **fast / typical**: fast = the 10th percentile of runs that actually went from one room to the other in one life (done well; stairs, lifts and jumps included), typical = the median. A cell in *italics* is an estimate for a pair nobody ran directly (shortest chain of typical legs). Built by `tools/mvd_features/research_2026_10/route_times_build.py`; the Game Report uses the same table for its clocks and perfect-timing lines.*
